# AI Agent Expired Domain Threat

This example demonstrates how an AI agent or any automated system can be vulnerable to expired domain name threats. It simulates an agent fetching configuration from a trusted source and then from a hypothetically compromised (formerly trusted) domain, highlighting the risk of blind trust and potential data leakage or malicious instruction execution.

## Language

`python`

## How to Run

Save the code as main.py. Run from your terminal: python main.py
